# Digital Image Processing
## Requirements
- [numpy](https://numpy.org/)
- [cv2](https://pypi.org/project/opencv-python/)
- [gradio](https://gradio.app/)
```bash
pip install numpy opencv-python gradio
```

## Usage
Run the `web_demo.py` and it will open your browser automatically:
```bash
python web_demo.py
```
There are five functions:
- Image Hue/Saturation/Brightness/Contrast Adjustment
- GAN-Based Image Generation and Editing
- Screen Content Replacement
- Image Denoising
- Image Brightening
